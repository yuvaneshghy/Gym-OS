# Feature Matrix

This table maps the core GymKit features to their planned release phases and the user roles that utilize them.

| Feature | Description | Phase | Roles |
|---------|-------------|-------|-------|
| **Multi-tenant Core** | One PB instance per client, dynamic tenant config | v1.0 | Admin |
| **Theme System** | Dynamic white-labeling (colors, logos) | v1.0 | All |
| **Auth & Roles** | Secure login, RBAC (Admin, Staff, Member) | v1.0 | All |
| **Membership Plans** | Create, edit, and assign gym plans | v1.0 | Admin, Staff |
| **QR Check-in** | Generate and scan QR codes for attendance | v1.0 | Member, Staff |
| **Payment Tracking** | Log cash/card payments, generate receipts | v1.0 | Admin, Staff |
| **Workout Plans** | Assign sets/reps/weights to members | v1.5 | Trainer, Member |
| **Class Bookings** | Schedule and book slots for Zumba, Yoga, etc. | v1.5 | All |
| **In-app Chat** | Direct messaging between trainers and members | v2.0 | Trainer, Member |
| **Hardware Integration** | Direct turnstile/RFID integration | v2.0 | Admin |
